# 云桌面箴言

## 重点

1. 反对复杂化，力求简单高效
2. 云桌面不是电脑的替代，而是电脑的补充
3. 反对全盘云桌面，应分批分次分场景进行实施
4. 相同配置的云桌面存在损耗，性能不可能优于物理机
5. GPU 是高性能云桌面的标配
6. POC 测试要站在管理者和决策者的立场
7. 云桌面存在价值是解决特定场景的特定问题，相比物理机并不存在成本优势
8. VDI、VOI、 IDV差异性大，不能混为一谈
9. 云桌面系统和用户数据要分开保存，用不同服务器承载和保存
10. 弄清底层需求，提供针对性的云桌面方案
